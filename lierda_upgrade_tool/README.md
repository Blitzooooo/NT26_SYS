# lierda 蜂窝固件下载工具
这是一个用于编译和下载 lierda 蜂窝固件的工具。该工具使用 PySide6结合Qt框架的C++开发，提供了友好的图形用户界面，支持固件编译、下载以及全量下载等功能。

## 功能特点

- **USB/UART日志显示、管理及日志配置**：显示模组运行日志，并提供日志配置选项
- **模组基本信息展示**：展示模组的基本信息，如基本信息、系统状态、网络信息、信号质量等
- **模组重启功能**：通过点击按钮重启模组
- **固件编译、下载、全量下载**：根据选中的应用、底包进行固件的编译、下载、全量下载操作,同时支持编译、烧录日志显示及进度展示
- **项目管理**：支持创建、删除和管理项目，支持选中的项目直接导入SDK中进行编译、烧录、读写文件系统等操作

## 系统要求

- **操作系统**：Windows 10/11
- **运行环境**：无需额外安装Python或其他依赖

## 使用方法

1. **获取可执行文件**
   - 从发布页面下载最新版本的打包文件
   - 解压后找到 `lierda_upgrade_tool.exe` 可执行文件

2. **运行工具**
   - 双击 `lierda_upgrade_tool.exe` 文件即可运行工具
   - 工具启动后会显示图形界面

3. **使用步骤**
   - 在界面中选择应用文件夹路径和底包文件路径
   - 点击相应按钮执行操作：
     - **编译**：仅编译固件
     - **应用下载**：下载应用固件到设备
     - **全量下载**：执行完整的固件烧录

4. **查看结果**
   - 操作进度会在进度条中实时显示
   - 详细日志信息会在日志区域显示
   - 状态信息会在底部状态栏显示

## 注意事项

- 确保选择的文件路径正确有效
- 下载操作确保设备已正确连接并处于下载模式

## 技术说明

本工具基于以下技术开发：
- **界面框架**：PySide6 (Qt for Python)
- **打包工具**：PyInstaller
- **C++扩展**：使用pybind11封装的核心功能
