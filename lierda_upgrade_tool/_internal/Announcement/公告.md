## SDK V0107 Release Notes

### 特殊说明

<span style="color:#d32f2f; font-weight:bold;">使用718_M系列芯片模组必须升级到该版本，否则会导致后续新批次模组启动异常。相关工具已同步升级，请使用最新版本的工具。</span>

### Added

- 新增硬件定时器liot_timer接口
- 新增支持VSIM功能
- 文件系统新增 liot_telldir，liot_seekdir，liot_rewinddir接口
- 新增tts直接开放8k/16k中英文库
- 新增底包F6D_D/F9D_D，支持3A算法
- 新增F7D_A，支持 NT26F7D0带votle底包
- 新增liot_jpeg接口以及示例demo
- router工程优化网速和稳定性；新增支持ipv6功能、支持CLAT
- fota demo新增串口升级示例
- 新增支持烧录时内置文件系统
- 新增支持模组型号 NT26F7D0、NT26F8D0、NT26F8D0-0K、NT26F8D0-0TK

### Changed

- 优化liot_audio接口、新增 spicodec 功能
- mqtt连接支持设置收发buff大小，收发超时，重连次数
- 将L_CT4IT00_YP00W_01_V04示例名字改成NT26FxDx_OpenKit、并新增demo_watch

### Fixed

- 修复第三方库lvgl编译问题
- 优化第三方mqtt异常处理死机的BUG
- 解决F6D系列sim2识别异常的BUG
- 优化了一些编译和注释
